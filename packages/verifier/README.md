# @longhand/verifier

**Lane:** Report and verifier. Verifier CLI + web page: checks a verification bundle's hash chain and witness signatures, re-folds the ledger and recomputes the report (shares the lane with `packages/report`).

This package is an empty shell created by the scaffold step. Contracts live in `@longhand/schema`; see `docs/BUILD.md` for the lane rules (work only inside this package, ask the coordinator for contract changes).
